# Frustrated-spin learning1

Sean Brady is originator and conceptual director. This additive GEN4 research
project studies the completed N1–120 atlas. It does not execute N>=121, alter
canonical answers, install learned authority, modify selectors or other projects,
or call hosted models. Runtime is an isolated, authenticated retained GEN4-P1
restoration; source-bound adapters execute through MATTER_SEARCH DomainSession.

Canonical N100/N105 are historical packet-family defaults. Their connected
N120-prefix counterparts are separately labeled inherited variants. N105 is a
retrospective structural-transfer case: no formal preregistered prediction located.
N108 was absent before the historical N120 launch; its causal skip rationale is
not established. N120 descends from the N96 frustrated graph, not the packet family.

The recovered installation names nine learned models, five original planners,
expanded planning, component solving, variable elimination and boundary reuse.
METHOD_DEFINITIONS.json explicitly maps these nine executable method families;
the campaign does not mislabel nine fitted models as nine distinct algorithms.

Controller flow: pre-execution graph atlas -> interpretable descriptive baselines
-> packet forensics and counterfactual exact routes -> scored structural questions
-> small full-density experiments and same-N variants -> independent certificate
checks -> fitted per-method cost updates -> next frontier. A local deterministic
question generator uses structural novelty, anomaly relevance and expected
information per estimated cost. Expensive spectra are not launched just to fill
scorecards. Structural-only alternatives are labeled as such.

Existing resource-manager snapshot/ownership lock is used without calling its
service-configuring launcher (owner prohibits service changes). One low-priority
CPU worker, up to two permitted CPU affinities, four-GiB worker address-space
limit, minimum six-GiB available RAM, five-GiB disk reserve,120-second experiment
wall ceiling. Workload snapshots precede admission. No available local CUDA;
no remote hardware lifecycle action. Swap is not used deliberately. The profile's
zero-swap setting is reported as a policy; this detached process does not claim
cgroup enforcement of that setting.

Default deadline eight hours from first actual campaign start, preserved across
restart. SIGINT/SIGTERM or STOP file checkpoints and stops the child. Failed and
interrupted experiments are retained and not retried indefinitely. The loop may
stop early when its admissible question frontier is exhausted. Checkpoints and
reports update after every experiment, each shorter than ten minutes.

Monitor: `cat GEN4/frustrated_spin_learning1/STATUS.json` and
`tail GEN4/frustrated_spin_learning1/QUESTION_LEDGER.jsonl`.
Stop: `touch GEN4/frustrated_spin_learning1/STOP` or the PID-specific SIGTERM
command in STATUS.json. No system service installed or modified. Keep workstation
powered and connected to local storage. Network is not needed after launch.

Results are project proposals only. A graph-partition certificate uses the known
component convolution identity, with independent edge-separation verification;
it is not presented as a novel theorem discovered from runtime correlation.
CPU cost models do not extrapolate GPU times. Future N121–144 predictions remain
conditional until source graphs are specified.
