# Fresh blind restart of the first GEN4 spin learning campaign

Sean Brady is originator and conceptual director.

This is a new eight-hour run of the first campaign's source-structure -> method -> exact work -> result objective. It starts with zero completed questions, zero learned observations, zero fitted research models and zero imported research certificates. Canonical N1–120 sources, historical measurements/answers and the verified mathematical runtime remain explicit inputs. This is fresh-state research, not a claim that GEN4 has never seen the atlas.

The stopped podrun3 and earlier research queues/results are not loaded. Historical conclusions from those runs do not seed the question generator. All scientific fits and investigations are recomputed in this directory.

## Self-follow-up

Every completed or failed experiment is passed to the local outcome-driven question policy. A result may generate competing-method measurements, an exact graph intervention, a same-N control, a structural neighbour, a retained-port question, a rule certificate, a counterexample search or a capacity-explanation question. Parent IDs and every generated child ID are recorded. Method timings feed fresh observations. Source-size labels alone never select the exact answer.

Question themes include atlas cost models, runtime discontinuities, packet/frustrated lineage forensics, source transfer, decomposition, arithmetic burden, symmetry, graph representation, coupling/fields, topology, boundary reuse and held-out structural controls. Scheduling combines expected information per cost, balance across themes and bounded waiting age. If the current queue empties, a review searches unvisited structural regimes and causal interventions. Two neutral results close a variant branch. The run may stop if no new useful admissible question remains; it does not fabricate novelty to occupy hardware.

This is local deterministic scientific question generation implemented through source-bound GEN4 DomainSession operations. It makes no hosted model calls. It is not unrestricted language-model reasoning.

## Execution

The original qualified focused and N120 branch-group solvers are retained:14persistent GPU owners,shared CPU preparation and batched exact NTT/CRT readout. A GPU comparison owns the entire team. CPU analysis and cheap exact work are admitted separately by the existing resource manager. GPU memory is checked by a separate preflight process before fork; CPU/RAM/process state and disk are checked for every experiment. No hardware reconfiguration or system service is used.

All newly solved canonical spectra must match full retained densities/ports. New changed-source solves require a certified explicit symmetry or two distinct exact elimination plans, with the complete density checks retained. Source-specific algebraic certificates are independently checked before CERTIFIED_EXACT_RULE. No learned rule is installed globally. N121–144 remain unexecuted.

Blind status is precisely fresh campaign state: canonical POST values remain verification/training targets and never enter models labeled PRE-execution predictors. N105 remains a retrospective packet-family case; no preregistered prediction is invented. N120's frustrated-source lineage remains separate.

## Process and records

Default8hours from this new launch. SIGINT/SIGTERM or STOP terminates only the campaign process group and checkpoints state. Completed IDs are skipped on recovery; interrupted questions produce a distinct follow-up rather than overwriting a precommit. Checkpoints occur after every question and at least every5minutes during a long experiment. Compact state and complete per-experiment native receipts are saved to the durable volume.

Monitor STATUS.json and QUESTION_LEDGER.jsonl. FIRST_PRINCIPLES_SEEDS.json records the initial scientific scope. FRONTIER.json records scored questions, actual generated children, theme coverage and branch termination. The controller's stop command is in STATUS.json. No earlier learned queue is copied.
