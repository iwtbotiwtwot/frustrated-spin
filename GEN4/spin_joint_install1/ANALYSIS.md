## What the accumulated work contributes

The canonical atlas is contiguous N1..120. Its low-cost N100/N105 packet sources
and the connected frustrated N96/N120 lineage retain different graph identities.
The new packet catalog extends three explicitly constructed source families

The reusable contribution is a compiler that recognizes computational structure:
independent components, repeated local operators, signed single-gateway bridges,

The original scalar packet result retains g(E,b). Joint work retains g(E,M,b).

uniform field, uniform pair coupling, ordered-boundary fields, partial boundary

crossing parameters, complete transformed densities and mixed moments.

## Connections that determine the installation

1. **Uniform completion is a collective observable.** For binary coordinates,
   sum(i<j)s_i*s_j=(M^2-N)/2. A completed graph with fill J0 therefore has
   E=Ecorr-J0*(M^2-N)/2. The expensive dense edge list need not dictate the
   contraction width. The correction graph and requested observables determine
   the computational route. Retaining M also permits changing the uniform pair
   coupling afterward, without rebuilding local factors or enumerating states.

2. **Boundary equivalence depends on the retained observable.** Equal complete
   gateway-conditioned energy polynomials permit the scalar bridge factor
   A(q)*(1+q^abs(J)). The same two messages need not be equal as polynomials in
   magnetization. The shared scalar compiler tests full equality before using
   this specialization; the joint compiler keeps signed gateway messages.
   Thus an optimization learned from the packet work is installed with its
   exact observable-dependent condition.

3. **Zero correction bridges reveal more independence than the original graph.**
   An original bridge whose coupling equals the complete fill has zero correction.
   Component splitting after this subtraction can expose repeated operators and
   integer polynomial powers even when the completed source is fully connected.
   This explains why visual graph density and computational cost can diverge.

4. **The Volume II C4 map makes M a useful existing source coordinate.** The
   retained map z=(s+t)/2+i(s-t)/2 gives E_spin=2H_phase and
   M=2*sum Re(z). A uniform binary field therefore becomes an exact phase-alignment
   term in the existing phase model. The new retained joint table supplies an
   exact response to that term, including boundary constraints and collective
   coupling. This is an immediate executable connection to the current Volume II
   work, rather than an inferred physical magnetic-unit assignment.

5. **Compiler reductions and native result reuse address different costs.**
   Local factor reuse reduces fresh arithmetic. Retained g(E,M,b) avoids repeating
   a solved state enumeration for new response parameters. Native request caching
   then avoids repeating an identical response query. These three levels retain
   separate execution/reuse labels and source identities.

## Exact execution and arithmetic

Scalar packet compilation uses full exact local energy polynomials, repeated
powers, balanced products and either verified equal-boundary specialization or
complete signed messages. Joint component calculation uses independent local
Gray-code/FLINT or CUDA/CPU tables, opposite-direction component contractions,
and two global no-carry polynomial encodings. Generic weighted graphs use the
existing finite-factor elimination machinery with joint polynomial coefficients.

Full scalar DOS, all retained ordered rows, configuration counts and first/second
moments remain. Joint magnetization marginals obey the exact boundary-conditioned
binomial identity. Independent direct enumeration checks small changed sources,
rational fields, uniform pair shifts, boundary fields, fixed M and every returned
crossing. Numeric comparisons normalize integer serialization without changing
any coefficient: an initial adoption assertion distinguished12 from"12"; the
preserved failed receipt and corrected comparison record that format issue.

## Installation and storage design

The upgrade extends14 existing GEN3_SPIN operations and the existing
GEN3_RESULT_APPLY path. It does not add a separate per-domain solver, selector,
service or campaign-only execution adapter. The native Store retains compressed
joint chunks, immutable source/plan identities and checkpoint dependency closure.
Self-contained export/import includes those chunks.

Large completed tables remain compressed and stream through the same READOUT.
Their native descriptors pin the manifest and each shard hash. Export explicitly
marks external-data requirements. Preserved local and T500 paths are registered
alongside pod custody; a missing archive reports its required location instead
of silently substituting a different source. This avoids duplicating gigabytes
in every CE session while keeping the data needed for a fresh response explicit.

The pod's prior capsule contained shared spin modules but still dispatched spin
calls through the older catalog entrypoint and lacked47 prerequisite retained
objects. The successor installation binds the existing shared dispatcher and
adds that immutable dependency closure transactionally. It preserves the prior
sealed runtime used by the running calculation. Both registry verification and
actual operation execution are required for its installed adoption.

Existing canonical answers, old models and their measured hardware scopes remain.
N100→N105 is a retrospective structural transfer; no preregistered prediction is
introduced. N108's historical scheduling cause is not inferred. New packet
continuations are not relabeled as canonical frustrated-source continuations.
