# Literature context and scope of size comparisons

This publication states measured coverage: all N1–1800 in six structured
source/fill cases, plus isolated exact N2000, N3000, N4000 and N5000 packages.
It does not assign a worldwide repository-size rank. Such a rank would require
a defined measure (files, bytes, distinct models, exact coefficients, or spin
counts) and a comparative inventory.

An identifiable N1296 example is the 36×36 square-lattice calculation in
Tröster and Dellago, *Wang–Landau sampling with self-adaptive range*,
Physical Review E **71**, 066705 (2005), Fig.2. It evaluates the joint density
in energy and number of up spins using Wang–Landau sampling. This is a sampled
two-variable density, whereas this repository's object also retains ordered
boundary spins and uses exact integer coefficients on structured complete graphs.
That paper therefore does not establish N1296 as the previous largest exact
g(E,M,b) calculation. A possible connection to the recalled number is identified;
a priority record is not inferred from it.

Primary paper: [Tröster and Dellago](https://doi.org/10.1103/PhysRevE.71.066705).
[Author-uploaded paper and figure](https://www.researchgate.net/publication/7670265_Wang-Landau_sampling_with_self-adaptive_range).

For a modern joint-density sampling comparison, Inácio, Ferreira and Amaral,
*Accurate Estimate of the Joint Density of States via Flat Scan Sampling*
(2022), explicitly presents a Monte Carlo estimator for g(E,M).
[Author manuscript](https://arxiv.org/abs/2203.02718).

Energy-only g(E), energy–magnetization g(E,M), and retained-boundary g(E,M,b)
are different observables. Graph topology, exact versus sampled arithmetic,
number of boundary states, and actual public data availability belong in any
comparison. The present release supplies these quantities directly, including
machine-readable support counts and the distinction between compact records
and expanded coefficients.

Literature lookup date: October 1, 2026. This is targeted context for the stated
N1296 comparison, not an exhaustive priority survey.
